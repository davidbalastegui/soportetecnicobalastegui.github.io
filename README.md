# Servicio Técnico Informático — web estática

Sitio web de una sola página preparado para GitHub Pages.

## Archivos
- `index.html`: página principal.
- `styles.css`: diseño responsive, animaciones CSS y estilos.
- `script.js`: menú móvil, animaciones al hacer scroll, año automático y FAQ.
- `privacidad.html`: página informativa inicial que debe revisarse/completarse antes de operar comercialmente.
- `assets/favicon.svg`: icono de la web.

## Publicar en GitHub Pages (opción A)
1. Conserva una copia de tu repositorio actual de PANIK.O.
2. Crea un repositorio nuevo llamado `davidbalastegui.github.io` si ese nombre está libre y es el que quieres usar como página principal. Si tu repositorio actual ya tiene ese nombre, no lo borres: guarda su contenido y haz copia de seguridad antes de sustituirlo.
3. Sube el contenido de esta carpeta a la raíz del repositorio elegido.
4. En GitHub, entra en **Settings → Pages** y selecciona desplegar desde la rama principal (`main`) y la carpeta `/ (root)`.
5. Espera a que termine el despliegue y abre la URL de GitHub Pages.
